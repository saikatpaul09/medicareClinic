# medicareClinic
This is a market side platform for clinics or hospitals allowing patients to consult online with doctors all over the country. It bridges the gap between economically backward people who dont't have access to good doctors. Through this simple app patients can consult with doctors online anywhere anytime. All they need is a smart phone and good internet. 
Tech Stack used :- React in front end, Tanstack query for query and caching, Zustand for react state management, vitest for testing.
Node.js with express for backend and node-pg-migrate for running migrations.
